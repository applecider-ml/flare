Feature-based Light-curve Aggregated Ranking Ensemble

A physics-features + gradient-boosted-trees classifier for ZTF photometric transients, with class-conditional conformal uncertainty and an anomaly layer for what falls outside the taxonomy. Calibrated probabilities, guaranteed per-class coverage, interpretable decisions, CPU-minutes to train, plain model files to deploy.

How it works

Engineered physics features plus tree-based ranking, with honest calibration on top.

1 · Features

160 physically-motivated features

Variability statistics, Bazin transient fits, colour evolution and cadence from each multi-band light curve, optionally joined with context available at alert time: Pan-STARRS host photometry, a Legacy-Surveys photo-z pseudo-absolute magnitude, Gaia DR3 and AllWISE point-source context.

2 · Classifier

LightGBM, two schemes

bts6: SN Ia · SN CC · SLSN · AGN · TDE · CV as a 5-way top level plus an SLSN head. broad5: the legacy AppleCiDEr taxonomy used by the tutorial notebooks. External blocks are randomly blanked in training, so a hostless or uncovered object degrades gracefully instead of being misread.

3 · Uncertainty

Mondrian conformal sets + anomaly energy

Per object, the set of classes guaranteed to contain the truth with probability ≥ 1−α, per class. Easy objects get one label; genuinely ambiguous ones get a short list for spectroscopic follow-up. An anomaly layer scores what is out of taxonomy, with the base rate that probability assumes.

How it reports

Renderings of genuine per-alert output on real ZTF objects. No invented values anywhere.

Coverage and detection

  • Conformal sets hold the 90% target: marginal 0.910; the 68-object TDE class sits at 0.853, within binomial noise. SLSN averages ≈ 2.1 labels per set rather than a silent misclassification.
  • Rare-class detection reaches 94% (TDE) and 86% (novae) at a 1% false-alarm budget.
  • The anomaly layer reads a narrower context (features + host + Gaia/WISE): M_pseudo and the counterpart block help classification but harm blind detection.

Install and use

Requires light-curve, lightgbm, and the numpy / pandas / scipy / scikit-learn stack.

Install

git clone https://github.com/applecider-ml/flare.git
cd flare
pip install -e .        # or: pip install -r requirements.txt

Command line

flare report ZTF19acbzgog ZTF22abkfhua -o report.html   # console page
flare predict ZTF19acbzgog                              # same as JSON

Photometry comes from BOOM when BOOM_URL and credentials are set, and from ALeRCE otherwise. Anything unavailable stays missing; never impute the external columns, pass NaN.

Python

import flare
clf = flare.load_classifier()          # bts6 by default

labels = clf.predict_from_files(["ZTF21abcdxyz.npz"])
sets   = clf.prediction_sets_from_files(["ZTF21abcdxyz.npz"])
energy = clf.anomaly_energy(clf.features_from_files([...]))

# everything from an object id:
from flare.fetch import fetch_events
from flare.context import context_features
